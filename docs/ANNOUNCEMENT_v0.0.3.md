## Reddit Announcement

Title: Galaxy Android v0.0.3 Released — Stability Fixes, New Movesets, Character Profiles & Co-op Assist

Download: https://github.com/OpenPort-Labs/Galaxy-Android/releases/tag/v0.0.3

Galaxy Android v0.0.3 is now available! This release focuses on save/load reliability, scene-transition stability, rendering fixes, performance improvements, and new gameplay features.

### Highlights
- Stability: Fixes for save-file indexing, stage reloads, scene transitions, audio synchronization, and display flickering.
- New moves: Odyssey-inspired Air Dive, Ground Roll, and Ground-Pound High Jump.
- Character profiles: Mario, Luigi, Peach, and Rosalina, each with unique movement characteristics.
- Co-op assist: Player 2 can trigger co-op jumps and spin attacks.
- Graphics: Vulkan FXAA, Cosmic Bloom, and improved visual presentation.
- Practice tools: Instant in-memory savestates and a speedrun telemetry HUD.
- Performance: Batched Vulkan texture uploads, improved frame pacing, and a 480p default resolution aimed at reducing GPU load.
- Other fixes: Bee Mario flight gauge, controller input, and external microSD storage detection.
